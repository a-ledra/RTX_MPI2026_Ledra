File organization for the RTX Bandwidth Project. 

Main contains all the important deliverables for algorithm testing. "main_faithful_select.m" allows for centralized algorithm testing. The code outputs minimum distance values.

Algorithms folder has two self-contained MATLAB codes for my greedy and quantile binning algorithms
"m" and "mlx" have MATLAB code and live editor files of simulation runs. Note the "m" folder has two daeintraplot codes, which test my algorithms against Dr. Edwards'.
Added simulation files are for reference.
